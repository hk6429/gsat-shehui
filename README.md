# 學測社會題庫

免費、免註冊的大學學測社會科歷屆試題分類練習網站。

目前已完成：

- 90–115 學年度學測社會考科
- 1,850 題，含 1,799 題選擇題與 51 題非選擇題
- 歷史、地理、公民與社會，以及跨科整合題
- 官方答案、非選擇題評分原則、答對率、鑑別度與選項分析
- 所有選擇題皆附自學解析
- 90 年舊制 A–E 單選與複選題，以及歷年複數答案／無答案判分
- 90–115 年大考中心官方試題與答案來源目錄
- 隨機／依序／由易到難出題、計時練習與整回模考
- Leitner 到期複習、錯題本、學習歷程匯出匯入
- 教師依篩選條件快速選題、產生學生測驗連結、列印題卷與下載 Word 檔
- 練習頁與查題頁提供低輸入問題回報，系統自動附題目脈絡並由後端推播至 Telegram
- 歷屆題圖皆裁切為照片、地圖、圖表或示意圖本體，不顯示整頁題本截圖

## 資料原則

- 題目與選項依大考中心官方試題逐題轉錄，不更動選項順序。
- 選擇題答案逐題比對官方參考答案。
- 非選擇題只使用大考中心公布的滿分參考答案與評分原則。
- 答對率、鑑別度及選項分析只採官方統計，缺少資料時不自行推估。
- 分類以大考中心社會考科測驗目標為錨點，再由真題歸納控制詞表。

## 驗證

```sh
npm test
```

驗證器會逐年檢查題數、題型、題組、圖片、分類、解析，並把答案、答對率、鑑別度與選項分析逐題比對官方中介資料；另會攔截整頁題本引用、缺圖、過小裁圖、重複圖片與 OCR 作答說明污染。90 年官方統計頁未提供逐題答對率、鑑別度與選項分析，因此該年明確保留為「無官方數值」，不做反推。批次覆核說明見 [`sources/90-113-REVIEW.md`](sources/90-113-REVIEW.md)，另有 [`sources/114/REVIEW.md`](sources/114/REVIEW.md) 與 [`sources/115/REVIEW.md`](sources/115/REVIEW.md)。

正式部署只使用 `npm run build` 產生的 `dist/`，不會把官方來源 PDF、校對文字或建置腳本公開成網站資產。

## 本機執行

這是原生 HTML、CSS 與 JavaScript 製作的靜態網站，可使用任一靜態檔案伺服器開啟專案根目錄。

題庫合併檔由下列指令產生：

```sh
./build-bank.sh
```
